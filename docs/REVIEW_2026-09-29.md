## Two useful words

- **Idempotent**: repeating an operation has the same effect as doing it once.
  Prompt example: “Make journal ingestion idempotent for retries, while preserving
  separate turns with identical summaries.” This specifies the intended duplicate
  handling much more precisely than “avoid duplicates.”
- **Provenance**: the recorded origin of information or an artifact.
  Prompt example: “Show the provenance of each decision: user instruction, verified
  tool result, or agent report.” This helps both of us distinguish authority and
  evidence from an unverified summary.
